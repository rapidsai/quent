| Rust callback → C caller (return) | Panic must never unwind into C for any callback. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Denial of Service | every new `extern "C"` callback | mitigate | `catch_unwind` at each new callback boundary (UB containment). |
| T-04-02 | Tampering / DoS | caller-owned `const char*` on marks/domains/registered strings | mitigate | Copy strings in-callback; registered strings captured once at registration, handle-only thereafter (Pitfall 3). |
| T-04-03 | Information disclosure / DoS | reading attribute members past `size` on new attribute-bearing kinds | mitigate | Honor `version`/`size` in each conversion (Pitfall 4, ASVS V5). |
| T-04-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages introduced in this plan; all deps established in plans 01-03 (audited `[OK]`). No install checkpoint required. |
